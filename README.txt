BALANCE - PARCIAL 2

COMO ABRIR
1. Abrir esta carpeta en Visual Studio Code.
2. Hacer clic derecho en index.html y elegir "Open with Live Server".
3. Usar los botones y el menu de abajo para recorrer las pantallas.

ARCHIVOS
- Cada pantalla tiene su propio archivo HTML.
- css/styles.css contiene los colores, tarjetas, botones y menu.
- js/app.js registra el Service Worker.
- sw.js guarda las paginas para abrirlas sin conexion.
- manifest.json contiene el nombre y los ajustes de la aplicacion.
- assets contiene el logo y la foto de perfil.

La aplicacion es una maqueta. No necesita una base de datos ni una cuenta real.
